
# Clay & Hearth - Handcrafted Ceramics Website

A fully functional e-commerce website for handmade ceramic tableware with AR visualization, custom commissions, and shopping cart.

## Features

- 🏺 **35+ handcrafted products** (mugs, bowls, plates, vases, sets)
- 🎨 **15 artisans** with individual collections
- 📱 **AR-enabled products** (15+ items)
- 🛒 **Shopping cart** with localStorage
- 📝 **Custom commission form** with artisan selection
- 💳 **Checkout system** with tax & shipping calculation
- 📱 **Fully responsive design**

## Quick Start

1. Save `index.html` in a folder
2. Open in any modern browser
3. No installation or dependencies needed!

## Pages

- **Home** – Featured products & artisans
- **Collections** – Browse all 35 products
- **Artisans** – Meet 15 makers, view their collections
- **Custom** – Commission unique pieces via modal form
- **AR View** – See AR-enabled products
- **About / Sustainability / Contact** – Info pages

## Tech Stack

- HTML5, CSS3, JavaScript (Vanilla)
- Font Awesome icons
- Google Fonts (Inter + Playfair Display)
- LocalStorage for cart persistence

## Browser Support

Chrome, Firefox, Safari, Edge (latest versions)
